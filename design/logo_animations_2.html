The spin is kept. Pick how the tree appears when a page opens, and how it looks while something is loading.

WHEN A PAGE OPENS

1 · Spin + fade inThe swirl spins up; the whole tree fades in and grows slightly as the spin settles. One soft movement.
2 · Spin + lift-offThe tree rises from below into place as the propeller spools up, like thrust. Lands with a tiny settle.
3 · Spin + growThe tree grows upward as one shape from the base (stem and branches together, no lone line).
4 · Spin + wingsThe branches start folded on the stem and open outward, bottom pair first, as the spin slows.
5 · Spin onlyThe tree is there from the start; only the swirl spins up. The calmest.
6 · Spin + light sweepSpin up, then a short bright glint runs up the tree once. Subtle, a bit premium.

WHILE LOADING / BUILDING

Busy a · Spin onlySteady spin, tree still. Easiest on the eye.
Busy b · Spin + breatheSteady spin, the tree gently grows and shrinks (2 s).
Busy c · Spin + hoverSteady spin, the tree floats up and down a little, like a drone hovering.
