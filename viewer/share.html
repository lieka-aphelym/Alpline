ALPLINE by lieka · open on your phone

How
  1. Phone and computer on the same Wi-Fi. At the field: switch on the phone's hotspot and connect the laptop to it.
  2. Scan the code with the phone's camera (or type the address in Chrome).
  3. The first time, Windows may ask whether Python may use the network: allow it on private networks. If the phone can't connect, set the Wi-Fi of the computer to Private (Windows Settings → Network → your Wi-Fi → Network profile type).
  4. On the phone, Chrome menu → Add to Home screen gives it an icon.

The phone can look, fly the simulator, follow live telemetry and build locations. Deleting and renaming only work on this computer. The radio stays plugged into the computer for live flights.
