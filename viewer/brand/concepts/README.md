# Logo concepts kept for later

From the author's sketches (November 2026). The drone schema is now drawn by `viewer/drone.js` (bigger propellers, no second
tail line) and used in the app: live link indicator, training box, build card, share page, empty pages. These
files are the original concept drawings.

- `drone-schema-*.svg`: the drone seen from above as the whole logo, without the swirl. It has the X frame, motor
  crosses, nested brackets for the propellers and their signal, and the signal arrow with landing legs in the middle.
- `drone-schema-simple-*.svg`: the same with single brackets, so it reads at smaller sizes.

Both get busy below about 32 px, so they suit large places (launcher splash, loading screen, about box, stickers)
better than the small header logo. Each comes in `-dark` (white + yellow) and `-light` (black + red).
